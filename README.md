# Foodie — Zomato-Inspired Food Ordering Clone

A responsive food discovery and ordering web app built using **HTML5, CSS3 and vanilla JavaScript**.

> Educational portfolio project. It is inspired by common food-delivery UI patterns and is not affiliated with or a reproduction of Zomato's proprietary code/assets.

## Features

- Responsive food-discovery homepage
- Restaurant cards with ratings, cuisine, delivery time and offers
- Search by restaurant, cuisine or dish
- Search suggestions
- Food category filtering
- Restaurant detail/menu modal
- Add items to cart
- Increase/decrease cart quantities
- Demo checkout flow
- Login/signup UI
- Favourite restaurants
- Persistent cart/favourites using `localStorage`
- Location selector UI
- Mobile responsive layout
- No framework or build step required

## Run locally

Open `index.html` in a browser.

For the best development experience, use VS Code + Live Server.

## GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save.

## Notes

The restaurant/food images use remote Unsplash image URLs, so an internet connection is recommended. The login and checkout are front-end demo flows only; no real authentication, payment, order API or database is connected.
